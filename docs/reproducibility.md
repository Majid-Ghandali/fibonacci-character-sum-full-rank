# Reproducibility Guide

This document describes how to reproduce the computational results for *An Explicit Evaluation of a Fibonacci Character Sum for Primes of Full Rank of Apparition*.

## Repository layout

- `Paper/`: LaTeX source of the manuscript.
- `code/`: Python verification suite.
- `results/`: committed and generated CSV, TXT, XLSX, JSON, LaTeX-table, and checkpoint outputs.
- `docs/`: additional notes, including this guide.

## Requirements

The tested release environment is:

- Python 3.12.7
- NumPy 1.26.4
- Pandas 2.1.4
- Numba 0.62.1
- OpenPyXL 3.1.5
- XlsxWriter 3.2.0

Install the pinned dependencies from the repository root:

```bash
python -m pip install -r Requirements.txt
```

`numba`, `pyarrow`, `openpyxl`, `xlsxwriter`, and `tkinter` are optional in the program: Numba accelerates the hot loop, PyArrow enables Parquet checkpoints, OpenPyXL/XlsxWriter enable spreadsheet output, and Tkinter enables the GUI. NumPy and pandas are required.

## Main script

The current entry point is `code/Fibchar_v1-0-1.py`. Run the deterministic smoke test with:

```bash
python code/Fibchar_v1-0-1.py --no-gui --self-test
```

The self-test checks five Appendix-A primes and five invariants for each prime. For the complete verification through `N = 2,000,000`, run:

```bash
python code/Fibchar_v1-0-1.py \
  --no-gui --N 2000000 --verify-b1 --out-dir results
```

The sequential pipeline supports checkpointing and resume:

```bash
python code/Fibchar_v1-0-1.py \
  --no-gui --N 2000000 --verify-b1 --resume --out-dir results
```

The parallel pipeline is available with `--parallel`, but it intentionally does not use checkpoint/resume:

```bash
python code/Fibchar_v1-0-1.py \
  --no-gui --N 2000000 --verify-b1 --parallel \
  --workers 8 --chunk-size 5000 --out-dir results
```

## Outputs

For `--out-dir results --N 2000000`, the program writes files with names including:

- `results/fib_char_N2000000_db.csv`
- `results/fib_char_N2000000_report.txt`
- `results/fib_char_N2000000_report.xlsx` (when spreadsheet dependencies are available)
- `results/fib_char_N2000000_main_theorem.csv` (with `--verify-b1`)
- `results/fib_char_N2000000_root_order_sign_checks.csv` (with `--verify-b1`)
- `results/fib_char_N2000000_empirical_claims.csv`
- `results/fib_char_N2000000_summary.json`
- `results/latex_tables/` (generated LaTeX tables)

The committed headline snapshot is [`results/corollary_B1_verification.csv`](../results/corollary_B1_verification.csv), and the committed full database is [`results/fib_char_db_N2000000.csv`](../results/fib_char_db_N2000000.csv). The filename `corollary_B1_verification.csv` is retained for backward compatibility although the report now calls the result the Main Theorem.

Checkpoint files are written during sequential runs and removed automatically after a successful finish. If a run is interrupted, use `--resume` with the same output directory and `N`.

## Computational summary

The reported run processed 148,933 primes up to 2,000,000 and found 26,407 primes with `alpha(p) = p - 1`; all matched the stated theorem with zero mismatches. The root/order/sign checks and empirical diagnostics are generated by the same release script and should be treated as computational evidence, not as a replacement for the manuscript proof.

## Mathematical quantities

The script distinguishes the manuscript sum `S(p)`, the rank-truncated sum `T_alpha`, and the full Pisano-period sum `S_p`. In the full-rank regime these agree because `alpha(p) = pi(p) = p - 1` and `chi_p(F_{p-1}) = 0`; outside that regime they need not agree.

## Notes

- The hot loop supports three character backends: QR lookup, bitwise Jacobi, and Euler-criterion modular exponentiation.
- Checkpointing occurs every 2,000 primes in sequential mode.
- Parallel mode uses multiple processes and fails hard if a worker chunk errors.
- For citation, use `CITATION.cff` and the repository's recorded release/archive DOI. The code currently labels `10.5281/zenodo.20707467` as the previous release; a future DOI should be added only after publication.
