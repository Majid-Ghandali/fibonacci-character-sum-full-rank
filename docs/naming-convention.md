# Fibchar naming convention

The repository uses the following canonical naming throughout current documentation and metadata:

- Software name: `Fibchar`
- Previous release: `Fibchar v1-0-0`
- Current release: `Fibchar v1-0-1`
- Source files: `code/Fibchar_v1-0-0.py` and `code/Fibchar_v1-0-1.py`

Older generated release artifacts may preserve historical spellings such as `FibChar`, dotted versions, or underscore-separated versions because changing them would invalidate their recorded checksums. Current source and documentation should use the canonical forms above.
